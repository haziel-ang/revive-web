Look up a domain or network

In OSINT choose a service, enter a value and select Look up. Start with domain RDAP, then use DNS for A, AAAA, MX, NS, TXT, CNAME, SOA, CAA or PTR records. Copy a returned address into IP registration, network/ASN, geolocation or reverse DNS to check it individually. Use autonomous system RDAP for an AS number.

RDAP.org redirects to the responsible registry. The summary displays published fields and the JSON response retains the details. IP locations supplied by Country.is are approximate. RIPEstat supplies the network prefix and AS numbers. A shared address may belong to a CDN.

TLS certificates and HTTP headers

Choose Published certificates to read issuances available from Cert Spotter. The crt.sh link opens certificate history. Historical issuance and the certificate presented by the server today are separate observations.

To inspect the current certificate, open the HTTPS site and view its certificate in your browser’s connection information. For headers, open Developer Tools, select Network, reload the page and select the document request. Read the response headers and HTTP status. On the HTTPS page you can open the domain and paste response headers to organize them locally. Desktop Revive also supports a direct TLS handshake and a HEAD request without redirects.

Username search

Choose GitHub, GitLab or both platforms. Run the search and open the returned profile. Service limits produce an unavailable result. Matching usernames across sites do not establish identity.

View in graph transfers possible profiles to the diagram. Use desktop Revive for extended Sherlock or Maigret searches. The web viewer accepts Maigret snapshots generated by Revive. HTML reports and raw engine JSON use different formats.

Graph, history and comparison

Enter a domain on the Graph page. Revive queries A, AAAA, NS, MX and the registrar. Unavailable sources are reported alongside result counts. Scroll the diagram or expand the textual relationship list.

Save in browser keeps a case in this browser profile. Export JSON to transfer it. Import reads a local snapshot and requires an explicit save to add it to history. Once two cases are saved, Correlate saved cases merges identical node IDs and lists shared resources. Deleting a saved case requires confirmation.

File verification

Select a file up to 128 MiB, optionally enter the expected 64 hexadecimal characters, and calculate SHA-256. Comparison happens in the browser. Obtain the reference digest from a trusted source.

Developer and LLM reference

JSON schema 1 uses target and createdAt, nodes with id, kind and label, and links with from, to and relation. Each endpoint must identify a node. The viewer accepts domain and username snapshots up to 2 MB, 1,200 nodes and 2,400 relationships. Node IDs determine cross-case matches. Preserve IDs when transferring a case.

Requests to public providers start with a user action. Imported snapshots and files selected for hashing stay on the device. CORS restrictions, rate limits and outages can prevent a response. The interface remembers language and theme in the browser. Provider data and raw JSON retain their original language.
